Goal — 왜

goals/ 폴더의 .md 파일이 그대로 목록이 됩니다. 뱃지는 미완료 task 수, 색은 그 목표의 time block이 물려받는 색. 맨 위 Inbox는 goal이 없는 잡일을 받는 특수 파일 — daily task라는 분류는 없고, task를 타임라인에 드래그하면 그게 곧 오늘의 task가 됩니다.

Write — 무엇

markdown이 곧 편집기입니다. 체크박스는 클릭으로 토글, ⠿ 핸들을 잡아 타임라인으로 드래그하면 배치됩니다. ^a1b2는 Obsidian 호환 block id — 배치된 task에만 생깁니다.

Commit — 언제

빗금 블록은 Apple 캘린더 일정(읽기 전용 배경), 컬러 블록은 내 time block입니다. 드래그로 이동, 아래 모서리로 리사이즈. 빈 시간을 드래그하면 팝오버로 바로 생성 — 제목만 쓰면 free block(점심), goal을 지정하면 그 goal 파일에 task가 생겨 main에도 나타납니다.
